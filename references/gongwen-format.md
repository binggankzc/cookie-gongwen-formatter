# 公文格式与校对规范参考

## 一、GB/T 9704-2012 关键参数

### 页面
- 纸张：A4（210mm × 297mm）
- 页边距：上 3.7cm、下 3.5cm、左 2.8cm、右 2.6cm

### 字体字号（目标字体需检测，替代字体不等于标准字体）
| 元素 | 字体 | 字号 | 备注 |
|---|---|---|---|
| 标题 | 方正小标宋简体 | 二号（22pt） | 居中，行距固定值 30pt |
| 正文 | 仿宋_GB2312 | 三号（16pt） | 行距固定值 30pt，首行缩进 2 字符 |
| 一级标题「一、」 | 黑体 | 三号（16pt） | 首行缩进 2 字符 |
| 二级标题「（一）」 | 楷体_GB2312 | 三号（16pt） | 首行缩进 2 字符 |
| 三级标题「1.」 | 仿宋_GB2312 加粗 | 三号（16pt） | 或用仿宋不加粗，视情况 |
| 页码 | 仿宋/宋体 | 四号（14pt） | 页脚居中，格式「— 1 —」 |

### 行距与缩进
- 行距：固定值 30pt（本技能预设，不作为完整符合标准的证明）。
- 首行缩进：2 字符（三号字约等于 32pt，但用「首行缩进 2 字符」方式最稳）。
- 段前段后：正文一般 0；标题与正文之间可留适当空。

### 署名与日期
- 发文机关署名、成文日期居右（右空 2-4 字）。
- 成文日期用阿拉伯数字（如 2026年11月9日）。

## 二、层级判定规则（脚本据此判断段落应套哪种样式）

按行首匹配，优先级从高到低：
1. 行首是「一、」「二、」…（中文数字+顿号）→ 一级标题（黑体）
2. 行首是「（一）」「（二）」…（全角括号+中文数字）→ 二级标题（楷体）
3. 行首是「1.」「2.」…（阿拉伯数字+点）→ 三级标题（仿宋加粗）
4. 其余 → 正文（仿宋）

标题行单独判定：全文第一段（或首个非空段）若较短、无句号，视为标题（方正小标宋二号居中）。

## 三、高频错别字 / 用词雷区（校对重点）

| 错误 | 正确 | 说明 |
|---|---|---|
| 帐号/帐户 | 账号/账户 | 与「账目」相关用「账」 |
| 截止…为止 | 截至… | 「截止」不直接接时间；接时间用「截至」 |
| 其它 | 其他 | 公文用「其他」 |
| 唯一 | 唯一 | 「唯一」正确，常见误写「唯一」没问题，警惕「维一」 |
| 的地得 | 按用法 | 定语后「的」、状语后「地」、补语前「得」 |
| 既使 | 即使 | |
| 复盖 | 覆盖 | |
| 再接再励 | 再接再厉 | |
| 布署 | 部署 | |
| 安祥 | 安详 | |
| 好像 | 好像 | 「好像」可，警惕「好象」（旧规范） |
| 反映情况 | 反映/反应 | 上报情况用「反映」，客观反应用「反应」 |
| 权力/权利 | 按语境 | 公权力用「权力」，公民权益用「权利」 |
| 营利/盈利 | 按语境 | 「营利」指经营牟利，「盈利」指获得利润 |
| 制订/制定 | 按语境 | 计划草案用「制订」，定下来用「制定」 |
| 撤销 | 撤销 | 公文用「撤销」，非「撤消」 |

## 四、其他校对检查点

1. **序号层级**：是否「一、」里套「（一）」再套「1.」，有没有跳级或混用（如「一、」下直接「1.」）。
2. **数字用法**：统计数字用阿拉伯数字，但「两、两件、两次」等量词前用中文；同一句/同段内数字体例一致。
3. **日期格式**：全文日期格式统一（要么「2026年11月9日」要么「2026-11-09」，不混用）。
4. **单位统一**：万元/元、%与百分点等不混用；同一指标单位前后一致。
5. **口径矛盾**：前后文同一数据、同一说法要一致（如前面「100人」后面「98人」）。
6. **指代不明**：「其」「该」「上述」等指代是否清晰。
7. **主谓/动宾搭配**：如「水平得到了提高」OK，「水平得到了完善」不当。
8. **缺要素**：正式文件是否有标题、主送机关、正文、落款（署名+成文日期）。
9. **重复啰嗦**：同一意思反复表述，可提示精简。

## 五、文种识别与结构核对（党政机关公文 15 种常见文种）

### 识别规则
读文件后，按「标题关键词 → 开头惯用语」优先级判断文种：
- 标题含「的通知」或开头「现将有关事项通知如下」→ **通知**
- 标题含「的报告」或开头「现将有关情况报告如下」→ **报告**
- 标题含「的请示」或结尾「妥否，请批示」「请批示」→ **请示**
- 标题含「的函」或结尾「特此函告」「敬请函复」→ **函**
- 标题含「会议纪要」或「纪要」→ **纪要**
- 标题含「的决定」→ **决定**；「的意见」→ **意见**；「的通报」→ **通报**；「的批复」→ **批复**
- 无法判断时，标注「未明确文种」，按通用公文核对。

### 各文种结构要点（核对时参照）

| 文种 | 标题惯用式 | 正文结构 | 开头惯用语 | 结尾惯用语 | 常见毛病 |
|---|---|---|---|---|---|
| 通知 | 关于…的通知 | 缘由 → 通知事项（分条）→ 执行要求 | 现就有关事项通知如下 / 现将…通知如下 | 特此通知 | 缺执行要求、事项不分明 |
| 报告 | 关于…的报告 | 情况 → 做法/成绩 → 问题 → 下一步建议 | 现将有关情况报告如下 | 特此报告 / 以上报告，请审阅 | 报告里夹带请示事项（报告不能请求指示） |
| 请示 | 关于…的请示 | 缘由 → 请示事项 → 请示要求 | 现将…请示如下 | 妥否，请批示 / 请予审批 | 一事多请、多头主送、与报告混用 |
| 函 | 关于…的函 | 缘由 → 商洽/询问/答复事项 | 特此函商 / 现函复如下 | 特此函告 / 敬请函复 | 语气过重、用了上行文语气 |
| 纪要 | …会议纪要 | 会议概况 → 议定事项（分条） | 会议认为 / 会议指出 | 无固定结尾 | 纪要与记录混淆、议定事项不明确 |
| 决定 | 关于…的决定 | 依据 → 决定事项 → 执行要求 | 经研究，决定如下 | 本决定自发布之日起施行 | 决定事项不清晰 |
| 意见 | 关于…的意见 | 缘由 → 具体意见（分条） | 现提出如下意见 | 以上意见，请结合实际贯彻执行 | 意见不具可操作性 |
| 通报 | 关于…的通报 | 事实 → 分析 → 处理/要求 | 现将有关情况通报如下 | 特此通报 | 事实与评价混写 |
| 批复 | 关于…的批复 | 引述来文 → 批复意见 | 你单位《…》（字号）收悉 | 此复 / 特此批复 | 缺引述来文标题和发文字号 |

### 结构核对时重点提示
1. 文种与用途是否匹配（该用请示的别写成报告）。
2. 开头/结尾惯用语是否用对、是否缺失。
3. 该文种的必要要素是否齐全（如请示要有「一事一请」、批复要引述来文）。
4. 语气是否与文种匹配（上行文用请示、报告口吻；平行文用函口吻）。

## 六、输出格式约定

改好的文件：`原文件名_公文格式.docx`，原文件不动。
校对清单在对话里逐条列出，格式：

```
【可能的问题】
1. [位置/原文] 问题类型 —— 建议改成 XXX
```

## 七、非正式文种格式规范（讲话稿/发言/调研报告/总结/汇报/体会/纪要等）

> 依据：《党政机关公文处理工作条例》《党政机关公文格式》(GB/T 9704-2012)，
> 以及济南市政府、本溪平山区纪委监委、湖南工学院、江西省委党校等机关发布的材料格式标准。非正式文种（不套红头、不按正式公文制发）遵循以下通用排版：

### 标题（阶梯式，逐级减小）
| 层级 | 字体 | 字号 | 对齐 | 说明 |
|---|---|---|---|---|
| 主标题 | 方正小标宋简体 | 二号（22pt） | 居中 | 不加粗；多行时排正宝塔/倒宝塔/菱形，不用上下等长的长方形 |
| 副标题 | 楷体_GB2312 | 三号（16pt） | 居中 | 排主标题之下，常用破折号「——」引导 |
| 标题下时间/署名 | 楷体_GB2312 | 三号（16pt） | 居中 | 时间加圆括号，如「（2026年1月15日）」；署名字间空一格、与正文隔一行 |

### 称谓 / 主送机关（关键：顶格不缩进）
- 如「尊敬的××、各位来宾：」「同志们：」——**顶格书写，不空两格**，后加全角冒号。
- 正文在称谓下一行，段首空 2 字，回行顶格。

### 正文与层级标题
| 要素 | 字体 | 字号 | 说明 |
|---|---|---|---|
| 正文 | 仿宋_GB2312 | 三号（16pt） | 首行缩进 2 字符，回行顶格；行距固定值 28~30pt（讲话稿可放宽到 32pt） |
| 一级标题「一、」 | 黑体 | 三号 | 首行缩进 2 字符，不加粗 |
| 二级标题「（一）」 | 楷体_GB2312 | 三号 | 首行缩进 2 字符 |
| 三级标题「1.」 | 仿宋_GB2312 加粗 | 三号 | 首行缩进 2 字符 |
| 四级标题「（1）」 | 仿宋_GB2312 | 三号 | 首行缩进 2 字符 |

### 结构层次序数（固定顺序，不可跳级/混用）
第一层「一、」→ 第二层「（一）」→ 第三层「1.」→ 第四层「（1）」

### 各文种附加要点
- **讲话稿/发言**：称呼顶格；正文口语化但规范；结尾「谢谢大家」类；通常无落款。
- **调研报告**：标题居中；可加副标题；正文三号仿宋；结尾有署名+成文日期（右对齐）。
- **总结/汇报/述职**：标题居中；正文三号仿宋；层级黑体/楷体；署名日期右对齐。
- **心得体会**：同总结类。
- **会议纪要**：标题「××会议纪要」居中；开头列时间、地点、主持人、参会人、记录人等要素；正文三号仿宋；「会议认为/会议指出」可加粗强调。

### 标点与数字
- 仅明确的中文语境标点使用全角；保护数字序号、英文、小数、网址、邮箱、路径和文件名。
- 数字、年份不能折行（回行时不能把数字拆开）。
- 除成文日期、结构层次序数及作为词素的数字用汉字外，其余用阿拉伯数字。
